Qwen4-Max 正式发布，基于新的 Qwen4 架构，拥有 2.4 万亿总参数、每 token 激活 71B、原生视觉能力和一百万 token 上下文。官方称其在 Work360 基准上从 47.74 提升到 52.69，平均任务成本从 4.43 美元降到 1.67 美元，降幅 62%，并在 Terminal-Bench 4.0 上显著减少 token 消耗。文章还展示了 3D 建模、游戏开发、产线规划等专业工作流。评论一方面期待更小尺寸的 Flash 与 27B 版本，另一方面抱怨现有 Qwen3.8 服务速度慢、拉低 agent 评测成绩。

3uBlock Origin 曝一键通用 XSS 漏洞
347 分 ｜ 95 评论 ｜ 已读原文 ｜ iter.ca
https://iter.ca/post/ubo-uxss/

安全研究者发现 uBlock Origin 的 Firefox MV2 版存在一键通用 XSS：恶意网站可通过 no-fetch-if 过滤器泄漏扩展内部 UUID，嵌入元素选择器 iframe，并用 postMessage 与换行注入构造任意受信任过滤器，从而在任意站点执行 JavaScript。漏洞已修复，修复方式包括让真正的选择器携带只有内容脚本知道的密码。作者说明漏洞由 GPT-5.6 Sol 找到，PoC 代码主要由 Claude 编写，自己负责验证与全文写作。评论感叹 uBlock 权限很大因此漏洞影响被放大，也有人讨论 AI 生成代码与人类写作声明的意义。

社区讨论
  • 有评论指出 uBlock Origin 为了工作必须拥有检查与修改任意页面的广泛权限，这天然放大了任何漏洞的破坏力。
  • 多人赞赏作者明确标注哪些由 AI 完成，认为这种人机分工声明值得在人类创作内容中推广。
  • 也有人泼冷水，认为 AI 训练到这类声明后会学会模仿，以显得更像人类写作；反对者则认为微调与对齐并不会自动解决幻觉。

41 分 ｜ 65 评论 ｜ 已读原文 ｜ twitter.com
https://twitter.com/GrapheneOS/status/2122079826257588569

GrapheneOS 在 X 上称 Linux 是对稳健软件架构与工具的拒绝：单体内核、内部缺乏隔离、用内存不安全代码写成，冷门驱动里的一个笔误就可能造成提权漏洞，并称 LLM 让找 bug 变容易后才让更多人看清这一点。评论反驳这是对 Linux 起源的误读，Linus 当年只把它称作 hobby，Unix 哲学与 Linux 内核设计也不是一回事。GrapheneOS 随后澄清只谈内核设计选择，不涉及 Unix API 或兼容性；也有人主张需要可验证的微内核，但问题在编码实践而非 C 语言本身。

社区讨论
  • 有人引用 Linus 最初称 Linux 只是爱好、不会像 GNU 那样庞大专业的说法，认为拿今天的标准回溯其创建动机并不准确。

  • 也有人指出 Windows 的工程基础更好却仍被诟病，说明架构争论不能只看单体内核与微内核的标签。
7Protomaps：自托管地图瓦片变得便宜又简单
329 分 ｜ 56 评论 ｜ 已读原文 ｜ bruceroettgers.eu
https://bruceroettgers.eu/blog/protomaps/

作者介绍用 Protomaps 的 PMTiles 自托管地图：整个瓦片集是一个文件，通过 HTTP Range 请求读取，可直接放到支持 Range 缓存的对象存储或 CDN 上。文章给出具体成本：139GB 世界地图五倍复制约每月 5 美元存储，每千次地图加载约 0.05 美元，比 Mapbox 每千次 5 美元便宜约百倍，并介绍 Bunny.net 的配置与限速防刷方法。评论补充直接访问 S3 的 Range 请求延迟不稳定，每块瓦片一次往返，有人改用 Martin 瓦片服务器或 Cloudflare Worker 缓存；也有人指出 Bunny 等支持 Range 缓存的 CDN 体验更好，PMTiles 已有 GDAL 驱动。

社区讨论
  • 有实践者说直接让浏览器向 S3 发 Range 请求延迟不可预测，浏览器和多数服务器也不会细粒度缓存，最后还是在前面放了 Martin 瓦片服务器。
  • 多人补充 CDN 差异很大，Bunny 的延迟约 100 到 300 毫秒且支持 Range 缓存，Cloudflare 则可用 Worker 把 z/x/y 请求转成 Range 并做区域缓存。
  • 也有人认为 PMTiles 已经相当普及，连 GDAL 都有官方驱动，说明单文件瓦片不再是实验性方案。
