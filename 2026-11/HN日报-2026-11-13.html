7Rust 1.100 发布
676 分 ｜ 258 评论 ｜ 已读原文 ｜ blog.rust-lang.org
https://blog.rust-lang.org/2026/11/12/Rust-1.100.0/

Rust 1.100 发布，最受关注的是经过 10 年、5 次失败尝试后 never 类型终于稳定，同时 Infallible 改为它的别名，并把 2024 之前版本的 never type fallback 从 () 改为 !，带来罕见的破坏性变更。此外稳定了 allocator_api 核心，Allocator trait 可用于 Vec 与 Box，新增 DropGuard 与 mem::conjure_zst，Cargo 支持报告未使用依赖与依赖冷却期，cargo install 默认复用 tarball 里的 lockfile。

社区讨论
  • 有评论列出最爱的四项：never 类型、自定义分配器、依赖冷却期以及 cargo install 默认使用自带 lockfile。
  • 长期关注者称 cargo install 不再需要 --locked 是盼了很久的改动，有人直言这是 Rust 最反直觉、最危险的坑之一。
  • 关于依赖冷却期存在拉扯：年初因供应链攻击被普遍支持，如今又有人担心会错过关键 0day 修复。
