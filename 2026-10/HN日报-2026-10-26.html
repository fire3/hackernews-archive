3OpenAI 与 Anthropic 数月内把 LLM 价格砍到最高 80%，为什么
312 分 ｜ 309 评论 ｜ 已读原文 ｜ minimaxir.com
https://minimaxir.com/2026/10/cheap-llms/

文章按时间线梳理两家公司从 GPT-5.6 到 GPT-6.1、从 Sonnet 5 到 Opus 5.5 的连续降价：GPT-5.6 Luna 一次性降 80% 至每百万 token 输入 0.20 美元、输出 1.20 美元，GPT-6 Sol 又把输入输出价格减半。作者强调 agent 写代码时缓存读取占总 token 支出的 96% 到 99%，Fable 5.1 把缓存读取费降 75% 等于整体成本降 70% 到 75%，因此缓存定价才是真正的战场。降价既来自双方针锋相对，也来自开源权重模型压力，例如 DeepSeek Flash V4.1 1017 在 Artificial Analysis 指数上从 24 升到 45，价格仍约为每百万 token 输入 0.15 美元、输出 0.60 美元。

社区讨论
  • 有评论预计 token 厂商会像移动数据运营商一样，吞吐和效率不断提升却逃不过商品化，很难独吞技术带来的经济收益。
  • 有人反驳无限量套餐不会到来，因为 agent 和子任务会自动烧掉大量 token；对方则认为会像运营商那样名义无限、极少数人触顶。
  • 关于无限套餐的形态，有人预测会按档位限制并行 agent 数量或模型智能，再退化成单线程或降智版本。
4十年前的老 CNN 在皮肤癌诊断上胜过前沿 LLM
558 分 ｜ 237 评论 ｜ 已读原文 ｜ lynchlab.net
https://lynchlab.net/llm-skin-cancer

作者用 MILK10k 中 200 个经活检确认的病灶测试 GPT-6 Astra 与 Claude Fable 5.1，两者六分类正确数分别为 84 和 85，即 42%，而基于 Inception v3、在单张 H100 上微调约二十分钟的 CNN 对了 125 个，即 62%，且能在手机浏览器里通过 WebGPU 本地运行。CNN 在 30 个黑色素瘤中认出 13 个，两个 LLM 分别只有 8 和 11 个；LLM 还各有偏好答案，Astra 把 75 个病灶判为基底细胞癌而实际只有 25 个，Fable 5.1 把 53 个判为光化性角化病而实际只有 20 个。作者也承认样本小、每个 LLM 只跑一次，并披露自己用 Claude Code 做分析与初稿。

社区讨论
  • 最高赞类比是计算器做乘除也胜过 LLM，认为这只能说明专用工具在窄任务上更强。
  • 有人回应说给 LLM 接上计算器工具，差距就消失了；但也有人指出性能不只是准确率，能耗和每次任务成本同样重要。
  • 有评论感慨为了算 1 加 2 要做上万亿次矩阵乘法，认为通用模型在专用任务上效率荒谬。
